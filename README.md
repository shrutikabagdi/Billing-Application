# Billing-Application
# Project Overview
This project is a Billing Software Backend. 
It provides APIs to: 
Manage Products 
Manage Customers 
Create Invoices 
Validate stock & auto-reduce stock 
Calculate GST & totals 
Return structured Invoice Response DTO

The system is designed with clean architecture using: 
✔ Controllers 
✔ Services 
✔ Repositories 
✔ DTOs 
✔ Models
